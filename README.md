# First scrapping script

Script de test pour apprendre le web scraping avec Selenium et BeautifulSoup.

Ceci est un script d'essai, réalisé dans un but d'apprentissage.

# Objectif du script 

Store Locator Scraper

Script Python permettant d'extraire automatiquement les informations des magasins présents sur une page web dynamique, puis de les exporter dans un fichier Excel.

Description

Ce script utilise Selenium pour charger une page web contenant une liste de magasins, BeautifulSoup pour analyser le contenu HTML et Pandas pour générer un fichier Excel contenant les données collectées.

Les informations récupérées sont :

Nom du magasin
Adresse
Latitude
Longitude
